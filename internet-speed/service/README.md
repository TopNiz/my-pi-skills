# Codimeo speed-test service

Bundled FastAPI API template for `https://speed-test.chain-it.com/`, served by Uvicorn. The production source is maintained in `TopNiz/internet-speedtest` and preserves the approved public UI alongside the API. This bundled template is API-only. New UI development stays in a separate local preview calling the remote API; it must not remove or replace the public UI without explicit user approval. It provides `/capabilities` (adaptive protocol version 1), `/ping`, `/download?bytes=N`, `/upload`, and `/upload-receipt/{id}`. Both directions are capped at exactly 1,000,000,000 bytes per request. Each capacity direction starts at 70 MB within one 10-second window; it adds a full 300 MB and then 1 GB only if the measured average predicts that the next stage fits the time remaining. There is no two-second or fixed-Mbps threshold. A planned deadline stop is normal. The separate load test uses up to 70 MB per direction within its own shared 10-second window. Adaptive ceilings `--max-size-mb 70`, `300`, and `1000` bound total payload at 280 MB, 880 MB and 2.88 GB, excluding overhead. The service never saves payloads or logs client addresses. Downloads are generated in 64 KiB chunks; uploads are counted and discarded as a stream. The client also uses bounded buffers and saves no download file, so there is nothing to delete afterward.

Capacity is always measured with download-only flows followed by upload-only flows. A separate simultaneous download/upload phase measures HTTP responsiveness under load and reports its throughput independently. Never use simultaneous-load throughput as the capacity result. Run the installed client with `python3 ../scripts/measure.py --json` from this service folder.

JSON includes `capacity_samples.download` and `.upload` time series with `{seconds, mbps, bytes}` interval samples. Final averages use actual received download bytes and complete or partial server-confirmed upload counts, divided by measured transfer time. At a planned cutoff the client cancels only its own flows and verifies upload receipts; unverified buffered progress is not capacity. Receipt verification may add a short wait outside the 10-second transfer window. HTTP probes time out after 10 seconds. Zero successful probes retain null timings and explicit failure/request counts. The API permits only exact browser origins in `SPEEDTEST_ALLOWED_ORIGINS`; production approves `http://127.0.0.1:63035` and `http://localhost:63035`. Other origins are rejected; there is no wildcard or credentialed CORS. CLI requests without Origin remain supported.

Receipts contain only byte counts and completion state. They expire after 30 seconds, are capped at 1024 records, and never contain payloads or client addresses. Tagged uploads have a 12-second server guard; receipt reads wait at most two seconds for finalization. The supplied deployment uses one Uvicorn worker because counters are process-local. Explicit fixed-volume options are retained only for compatibility diagnostics.

Before enabling adaptive measurements, install the speed-test-specific Nginx body allowance (`1000m`) and idle timeouts (`1800s`). The API still enforces the decimal 1 GB limit. Route receipt endpoints through the same speed-test location with burst 120 (including preflights) so a single adaptive run fits the unchanged sustained request limit. The normal container workflow does not modify host Nginx; obtain approval for that separate host change. Do not run full 1 GB acceptance tests without explicit approval.

The deployment target is `rg.fr-par.scw.cloud/chain-it/internet-speedtest` on `codimeo.com`. [The GitHub Actions workflow](.github/workflows/publish-image.yml) builds and smoke-tests this image, pushes immutable and moving tags, then uses a dedicated SSH deploy key to update a standalone Compose project on the host. It expects repository secrets `SCW_ACCESS_KEY`, `SCW_SECRET_KEY`, `CODIMEO_DEPLOY_SSH_KEY` and `CODIMEO_KNOWN_HOSTS`. The container binds to `127.0.0.1:18010` behind Nginx TLS.

The single public API endpoint is `https://speed-test.chain-it.com/`. The app is intentionally unauthenticated; Nginx applies rate and body-size limits, and the container port is not exposed publicly. See `deployment.md` for host configuration and recovery details.
