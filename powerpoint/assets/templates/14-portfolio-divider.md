# Slide 14: Portfolio Divider

## Description
A very large question mark occupies a pale panel on the left. A green L-shaped frame and a dark block on the right carry the words “Portfolio Presentation”. Supporting text is set inside the dark area.

## Geometric language
The design uses a large pale rectangle, an L-shaped green frame, a black or navy rectangular panel, and oversized display typography. The partial frame implies an unfinished or soon-to-be-revealed portfolio.

## Useful when
Use it as a section divider before case studies, project examples, product pages, or a portfolio review.
