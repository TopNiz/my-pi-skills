# Slide 16: Process Chevrons

## Description
Four colored chevrons point right in a horizontal sequence. Each step has a small heading and description above or below it, with a pale gray arrow shape extending behind the sequence.

## Geometric language
The main devices are chevron-ended rectangles, a large background arrow, small horizontal rules, and repeated text blocks. The directional point on every chevron makes progression unambiguous.

## Useful when
Use it for a four-step process, lifecycle, decision sequence, implementation method, or ESG reporting workflow.
