# Slide 18: Bar Chart

## Description
A grouped bar chart on the left compares four categories using paired green and blue bars. On the right, four colored title bars align with four explanatory text blocks.

## Geometric language
The chart uses a horizontal baseline, light gridlines, and repeated vertical rectangles. The right-side rectangles form a legend or commentary column that maps narrative points to the chart colors.

## Useful when
Use it for category comparisons, before-and-after results, benchmark data, or four metric explanations beside a chart.
