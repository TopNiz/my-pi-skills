# Slide 25: KPI Table

## Description
The left side contains two KPI sections with green progress bars at 95% and 65%. The right side contains a compact comparison table with orange and yellow column headers. A wide gray “Add Text” callout spans the bottom.

## Geometric language
The layout combines horizontal progress rectangles, percentage labels, thin divider rules, a table grid, and a rounded bottom callout. The two-column split separates visual performance indicators from detailed tabular evidence.

## Useful when
Use it for an executive dashboard, scorecard, audit summary, performance review, or ESG reporting slide combining KPIs and detail.
