# Slide 31: Stacked Bars

## Description
Three stacked vertical bars compare Text 1, Text 2, and Text 3. Each bar is divided into blue, yellow, and orange segments with percentages. On the right, three colored tables provide supporting detail.

## Geometric language
The chart uses stacked rectangles with numeric labels, a horizontal baseline, light gridlines, and three aligned table blocks. Color segments make composition visible rather than showing only totals.

## Useful when
Use it for portfolio composition, budget allocation, emissions mix, resource distribution, or comparing the makeup of three scenarios.
