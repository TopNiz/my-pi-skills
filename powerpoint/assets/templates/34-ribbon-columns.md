# Slide 34: Ribbon Columns

## Description
Four tall colored columns are arranged across the slide. Each column has a pale vertical backing, a slanted ribbon title from Text A to Text D, a second ribbon carrying explanatory text, and a bottom icon.

## Geometric language
The repeated structure uses vertical panels, angled parallelogram ribbons, small folded ribbon tails, and icon areas. The four columns make the slide modular and easy to repurpose.

## Useful when
Use it for four initiatives, service lines, communication channels, or a set of parallel ESG programs.
