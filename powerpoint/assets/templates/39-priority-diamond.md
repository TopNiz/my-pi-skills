# Slide 39: Priority Diamond

## Description
Four colored diamond or kite-shaped blocks surround a central diamond labeled “NO.1 Presentation”. Each outer block contains an icon and a nearby text callout.

## Geometric language
The central diamond creates a focal point, while four surrounding diamonds form a compass-like arrangement. Thin connectors and repeated callout blocks tie each priority back to the center.

## Useful when
Use it for four strategic priorities, a central objective with four enablers, stakeholder dimensions, or a prioritization framework.
