# Slide 41: Dark Columns

## Description
A dark two-column layout places an ESG globe image in a narrow left column and a translucent dark text panel in the larger right column. A small circular icon and a green footer message complete the composition.

## Geometric language
The slide uses a vertical column split, a large rounded or translucent rectangle, and small circular icon accents. Strong contrast between image and panel makes the text readable while preserving the visual theme.

## Useful when
Use it for a case-study narrative, a text-heavy explanation with one supporting image, or an executive statement with a visual anchor.
