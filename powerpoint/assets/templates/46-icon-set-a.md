# Slide 46: Icon Set A

## Description
A five-row icon library is organized by color. Green icons cover communication, analytics, charts, and global themes; orange icons cover office devices and presentation tools; yellow icons cover learning and creativity; blue icons cover documents and controls; gray icons cover awards, objects, and emotions.

## Geometric language
Each icon is a compact, flat vector silhouette with a consistent stroke and filled style. The rows use color as a category system, while the left green information panel explains resizing and changing fill or line colors.

## Useful when
Use it to add consistent visual markers to dashboards, process steps, KPIs, stakeholder maps, or presentation section labels.
