# Slide 47: Icon Set B

## Description
This icon library is more specialized. Green and orange rows focus on organs, health, and medical concepts; yellow includes science, pharmacy, business, and network symbols; blue includes laboratory, finance, travel, and profile icons; gray includes social media, lighting, flags, and recycling.

## Geometric language
The icons are flat, monochrome vector silhouettes arranged in evenly spaced rows. Consistent sizing and color bands make the set readable as a visual vocabulary rather than a random icon collection.

## Useful when
Use it for health, social impact, employee wellbeing, stakeholder engagement, or ESG material that needs specialized symbols.
