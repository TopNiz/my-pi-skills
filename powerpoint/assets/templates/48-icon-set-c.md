# Slide 48: Icon Set C

## Description
A general-purpose icon library is arranged in five color rows. Green covers people, relationships, hearts, cameras, video, megaphones, and microphones; orange covers security, targets, travel, luggage, aircraft, and cars; yellow covers sound, batteries, phones, power, radiation, and location; blue covers media, settings, home, finance, and services; gray covers weather, recycling, religion, and fire.

## Geometric language
The set uses flat, single-color vector silhouettes with a consistent visual weight. The five horizontal rows and the left instruction panel make recoloring and reuse straightforward.

## Useful when
Use it for general-purpose diagrams, service blueprints, risk maps, communication plans, digital products, or supporting labels across an ESG deck.
